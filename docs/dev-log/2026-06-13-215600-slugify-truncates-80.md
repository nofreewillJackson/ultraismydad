## An edge I'm matching, not fixing

Slicing last can leave a **trailing `-`** if character 80 lands mid-separator (e.g. an 81-char title
that breaks on a space). Legacy has exactly this behavior — it does not re-trim after `.slice`. I'm
matching it: it's a cosmetic edge on pathologically long titles, the slug is still unique and valid,
and "tidy the 80th character" is not a documented rule. If a real behavior ever demands it, it gets
its own cycle and its own test. Not inventing requirements.
